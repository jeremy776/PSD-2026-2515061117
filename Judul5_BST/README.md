# Tugas Akhir BST Mahasiswa

[Link YouTube](https://youtu.be/V5AmI46TxEo?si=8AecFenFwfAASJc1)

Program ini adalah aplikasi sederhana berbasis Python yang menggunakan Binary Search Tree (BST) untuk mengelola data mahasiswa berdasarkan NPM. Pengguna dapat menambah mahasiswa baru, mencari data mahasiswa dengan NPM, menampilkan seluruh data secara urut naik berdasarkan NPM, dan melihat jumlah mahasiswa yang tersimpan. Pada versi tugas akhir, data nama mahasiswa disimpan terpisah dari struktur BST sehingga BST dipakai untuk menjaga urutan dan mempercepat pencarian, sedangkan bagian menu interaktif membuat program mudah digunakan lewat terminal.
